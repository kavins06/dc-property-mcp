# v0.4.1 production release evidence

Release date: 2026-07-28

## Incident

The request "Give me all data available on 4800 E Capitol St NE in DC Quoin"
returned only tax history and described the other available domains as not yet
retrieved. This was incorrect: the database contained property, assessment,
ownership, sale/deed, permit, license, inspection/enforcement, and
building/land records for SSL `5140--0088`.

## Root causes and corrections

1. The MCP catalog exposed separate domain tools but no exhaustive
   single-property operation. Migration `0027_complete_property_record.sql`
   and Worker v0.4.1 add `get_complete_property_record`, which aggregates all
   nine sections and reports explicit continuation calls if a bounded section
   remains.
2. Address normalization abbreviated `EAST` to `E`, while the indexed address
   retained `EAST CAPITOL`. Migration `0026_capitol_address_resolution.sql`
   canonicalizes East, North, and South Capitol aliases and removes a trailing
   natural-language `in DC`.
3. The staged Worker check used a custom-domain version-override header that
   continued to serve the stable version. The deployment gate now verifies
   Cloudflare's exact version-specific preview URL at zero production traffic.

Both migrations have explicit down paths under `db/rollbacks/` and
least-privileged contracts under `db/tests/`.
