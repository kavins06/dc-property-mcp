# v0.4.4 production release evidence

Release date: 2026-08-04

## Scope

This patch makes tax and assessment source references directly useful to a
human verifier.

- sends users to the official MyTax.DC.gov real-property search
- supplies separate square, suffix, lot, and address lookup values
- retains the legacy MyTax route as a fallback
- keeps machine-facing evidence separate from the user-facing `sources`
- omits destination-specific instructions
- updates vulnerable transitive dependencies without adding a package

The deployed Worker source commit is `b268f21`; release execution used
`51023c9`.
